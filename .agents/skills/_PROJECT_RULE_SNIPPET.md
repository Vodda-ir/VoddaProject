# Suggested project rule

Use `copywriting` for marketing/public website copy and `ux-writing-content-design` for in-product UI copy. For Persian/Farsi output, always load the Persian reference bundled with the active skill. Run `humanizer` only after factual, strategic, and UX correctness is established. Humanization must never invent claims, alter domain meaning, weaken error recovery, or create inconsistent terminology.

When `ui-pro` is used, treat copy as part of the design review: marketing surfaces use `copywriting`; product surfaces use `ux-writing-content-design`; then apply `humanizer` as the final prose pass.
